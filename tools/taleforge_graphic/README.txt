taleforge_graphic — ComfyUI를 직접 안 만지고 쓰는 그림 생성 도우미
================================================================

이건 뭔가요?
----------------
새로 만들 taleforge 게임의 그림을, ComfyUI의 복잡한 노드 화면을 직접 안 만지고
간단한 화면에서 몇 번 클릭으로 만들어 보는 실험용 도구입니다. 카메라 각도·장르
같은 건 이 도구가 단정하지 않습니다 — 화면에 입력한 설명을 (원하면 수식어
없이 그대로) 보내서 결과를 보는 용도이고, 실제 에셋 디자인은 Fable/Opus가
나중에 정합니다.

준비물
----------------
1. ComfyUI가 이미 켜져 있어야 합니다 — 기존에 쓰시던 'simple ui confirm' 폴더의
   START.bat을 실행하면 ComfyUI도 같이 켜집니다(이미 알고 계신 방법 그대로).
   꼭 그 도구일 필요는 없고, ComfyUI가 http://127.0.0.1:8188 에서 켜져 있기만 하면 됩니다.
2. Python 3.10~3.12 ('simple ui confirm'을 이미 쓰고 계시면 이미 설치돼 있을 거예요).
3. Node.js (이 저장소의 tools/pixelart-gen/ 안 pixelate.js를 호출해서 도트 변환에 씁니다 —
   taleforge 본체를 빌드할 때 쓰던 것과 같은 Node입니다).

쓰는 법
----------------
1. ComfyUI를 켠다.
2. 이 폴더의 START.bat을 더블클릭한다 (처음 실행하면 필요한 패키지를 자동으로 설치합니다, 1~2분).
3. 자동으로 브라우저가 안 열리면 http://127.0.0.1:7861 로 직접 들어간다.
4. 화면에서:
   - "어떤 종류" 고르기 (무기/아이템 아이콘 / 타일 / 몬스터 / 캐릭터 스프라이트 / 장면 / 이펙트)
   - "무엇을 그릴지" 설명 쓰기 (영어로 쓰면 더 잘 그려집니다 — 예: "a glowing ice sword with blue runes")
   - 체크포인트(모델) 고르기 — 🔄 버튼으로 ComfyUI에 실제 설치된 목록을 가져옵니다
   - "🖼 미리보기 생성" 클릭 → 큰 원본 그림이 먼저 나옵니다 (아직 도트 아님)
   - 마음에 들면 "🧱 픽셀아트로 저장" 클릭 → 작은 진짜 도트 그림으로 강제 변환돼서 저장됩니다
     (outputs/pixel/ 폴더, outputs/raw/ 에는 원본도 남아요, outputs/history.jsonl 에 기록)

픽셀아트 전용 모델 받기 (새 기능)
----------------
화면 위쪽 "📦 픽셀아트 모델 받기"를 펼치면:
1. 먼저 **ComfyUI models 폴더 위치**를 한 번 적고 저장하세요 — 기존에 쓰시던
   'simple ui confirm' 폴더 안의 `models` 폴더와 같은 곳이면 됩니다
   (예: `C:\Users\이름\simple ui confirm\models`). 한 번만 하면 계속 기억됩니다.
2. 추천 목록의 "받기" 버튼을 누르면 진행률이 뜨고, 끝나면 체크포인트/LoRA
   목록이 자동으로 다시 불러와집니다(화면에서 바로 선택 가능).
3. 추천 1순위는 **Pixel Art XL**(SDXL용 LoRA, 약 171MB) — 지금 쓰시는
   체크포인트를 안 바꾸고 그대로 얹어서 쓸 수 있어요. LoRA 목록에서 골라
   강도(기본 0.8)를 조절하면 됩니다. 프롬프트에 "pixel art"를 넣으면 더 잘
   먹혀요.
4. 추천 목록에 없는 다른 모델은 "직접 URL로 받기"에 HuggingFace의
   `.../resolve/main/....safetensors` 형태 주소를 붙여넣으면 받을 수 있어요
   (civitai 주소는 로그인이 필요한 경우가 많아 이 기능으로는 잘 안 될 수
   있습니다 — civitai 모델은 보통 브라우저로 직접 받아서 models 폴더에
   넣는 게 더 확실해요).
5. **솔직히**: 추천 목록의 주소는 제가 2026-10-28에 웹 검색으로 찾은
   것이고, 이 세션은 huggingface.co에 직접 접속할 수 없어서 실제로
   받아지는지 테스트는 못 했습니다(다운로드 코드 자체는 가짜 서버로
   검증함). 눌러서 오류(특히 404)가 나면 알려주세요 — 주소만 고치면
   됩니다.

결과물은 어디 쓰나요?
----------------
지금은 "이 스타일이 실제로 어떻게 나오는지 실험"하는 용도입니다. Fable로 새 게임을 설계하고
Opus로 구현을 시작하면, 그때 실제로 필요한 구체적인 에셋 목록에 맞춰 이 도구(또는 이 도구의
ComfyUI 호출 로직)를 다시 연결할 계획입니다 — 지금 만든 그림을 그대로 최종 에셋으로 쓰라는
뜻은 아닙니다.

알아두면 좋은 것
----------------
- 체크포인트(모델)에 따라 그림 스타일이 크게 달라집니다. 지금 갖고 계신 체크포인트
  (RealVisXL 등)는 사실적인 인물 사진 전용이라 픽셀아트/타일에는 안 맞을 수 있어요.
  픽셀아트 전용 체크포인트(civitai.com 등에서 검색)를 따로 받아서 models/checkpoints
  폴더에 넣으면 체크포인트 목록에 자동으로 나타납니다.
- "그리드 크기"/"색상 수"를 조절하면 도트 느낌이 달라집니다 — 숫자가 작을수록 옛날 콘솔
  느낌(거친 계단, 색 적음), 클수록 요즘 인디게임 느낌(부드러운 음영). taleforge 본체의
  아이콘은 64/48을 기본으로 씁니다.
- 생성이 오래 걸리면(특히 처음 켰을 때 모델을 불러오는 중) 화면에 "그리는 중..."이 계속
  보입니다 — ComfyUI 창(검은 창)에 오류가 없는지 같이 확인해 보세요.
- "상태" 칸에 뜬 오류 메시지는 되도록 원인을 한글로 풀어서 보여주지만, 낯선 오류면
  괄호 안의 영어 원문을 그대로 알려 주시면 더 정확히 도와드릴 수 있습니다.

이 도구는 어떻게 만들어졌나요 (솔직하게)
----------------
사용자님이 이미 만들어 쓰시던 'simple ui confirm' 도구의 구조(화면 흐름, ComfyUI 호출
방식 — 큐 등록→상태 확인→이미지 받기, 오류를 한글로 풀어 주는 방식 등)를 많이 참고해서
만들었습니다. 다만 그 도구는 인물 사진 전용이라, 내용(얼굴 고정, LoRA 학습, Sexy 옵션 등)은
가져오지 않았습니다 — "ComfyUI를 복잡한 노드 없이 쉽게 쓴다"는 틀만 가져와 픽셀아트용으로
새로 짰습니다.

이 코드를 만든 세션은 GPU도 ComfyUI도 없는 클라우드 샌드박스에서 작업했습니다. 그래서
①ComfyUI API 모양을 흉내 낸 가짜 로컬 서버로 "큐 등록→상태 확인→이미지 받기" 왕복 코드가
정상적으로 도는지 ②실제 pixelate.js로 테스트 이미지를 도트 변환하는 것 ③Gradio 화면
코드가 오류 없이 만들어지는 것(gradio를 설치해서 import 확인) — 이 세 가지는 확인했지만,
**진짜 ComfyUI로 실제 그림이 잘 나오는지, 체크포인트 목록이 화면에 정확히 뜨는지, 전체
화면이 브라우저에서 보기 좋게 배치되는지는 사용자님 PC에서 처음 확인됩니다.** 이상하거나
불편한 부분이 있으면 그대로 알려 주세요.
